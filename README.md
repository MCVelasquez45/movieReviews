# 🎬 Movie Buzz

## 📖 Overview
**Movie Buzz** is a web application that allows users to browse and discover movies using data fetched from **The Movie Database (TMDb)**. The app displays a curated list of movies, showcasing their posters, descriptions, release dates, and ratings. It also features a dynamic **filmstrip carousel** that highlights trending movies.

## 🚀 Features
- 🎞️ **Movie Listings** – Displays a list of movies with their posters, titles, overviews, and ratings.
- 📅 **Release Date & Popularity** – Shows when a movie is released and its popularity score.
- 📽 **Filmstrip Carousel** – Automatically updates and displays trending movies.
- 🔄 **Real-time Data Fetching** – Retrieves movie data dynamically from a local server (`localhost:3500/movies`).
- 📱 **Fully Responsive** – Optimized for both desktop and mobile screens.

## 🛠️ Technologies Used
- **HTML5** – Structuring the webpage.
- **CSS3** – Styling and making the layout responsive.
- **Bootstrap 4.5** – Frontend framework for styling.
- **JavaScript (ES6)** – Fetching and displaying movie data dynamically.
- **jQuery** – DOM manipulation and event handling.
- **TMDb API** – Fetching movie data (Requires an API key if hosted externally).
